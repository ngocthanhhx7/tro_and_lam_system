# TRO & LAM search copy

Use this skill when writing or reviewing Vietnamese public copy, page titles, descriptions, headings, image alt text, FAQs, structured data, or search visibility for this project.

Before changing public claims, read the relevant sections of:

- `doc/brand/README.md` for identity, image disclosures, and current language rules.
- `doc/planning/interface-follow-up-plan.md` for approved copy and media limits.
- `doc/brand/media/photography-sources.md` and `doc/brand/media/video-sources.md` when describing media.
- `doc/release/acceptance-coverage.md` for current SEO limitations and unresolved owner inputs.

## Copy decisions

- Write natural Vietnamese with diacritics. Name the visible product or craft topic directly; use search phrases only where they help the reader understand the page.
- Keep the editorial tone calm, precise, and culturally respectful. Prefer concrete, sourceable descriptions over superlatives or sales pressure.
- Use facts present in the published catalog, owner-approved project material, or a cited authoritative source. Preserve attribution when describing heritage, techniques, makers, materials, origin, or dates.
- Never invent product material, dimensions, price, stock, maker, technique, origin, awards, sustainability, authenticity, delivery, or warranty claims. Ask for the missing owner-approved fact or write around it.
- Concept images are inspiration, not proof that a photographed item is an available SKU. Keep the visible concept disclosure and honest alt text beside them.
- Do not claim that AI search citation, rankings, clicks, or traffic are guaranteed. Do not add keywords, FAQs, statistics, quotations, or AI-only text just to influence crawlers.

## SEO/GEO implementation

- Give each public page one clear subject, a useful title and description, semantic heading order, descriptive links, and accessible image text based on what is actually shown.
- Make structured data agree with visible content and verified catalog values. Add a FAQ only when customers need those answers; use FAQ markup only when current official search-engine guidance and the actual page qualify.
- Do not add `llms.txt`, crawler-specific copy, canonical URLs, absolute social URLs, or a sitemap based on guesses. Domain-dependent output waits for the project owner to configure and confirm the production domain.
- For search guidance or cultural facts that need research, check current primary/official sources. Follow the project handoff rule for Agy research; if access or quota blocks it, report that limitation and do not present the research as complete.
- Keep visible copy useful to customers first. GEO means making accurate, well-structured information understandable and attributable, not manufacturing signals.
